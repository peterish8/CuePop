# CuePop Project

CuePop is an image-first live presentation platform. A host builds an ordered timeline from slide images and audience moments, starts a room, and independently operates a projector, presenter console, phone remote, and attendee browser experience.

## Core value

Turn a one-way presentation into a controlled live room where attendees can participate within seconds and leave with a curated keepsake.

## Included in this repository

- Host registration and sign-in
- Deck workspace and image-first storyboard
- Slide image upload and reorder
- Multiple-choice polls and quizzes
- Dynamic QR join screen and short code
- Socket.IO synchronized stage, attendee, presenter, and remote views
- Unique voting and reconnect-safe attendee identity
- Curated Canvas-generated keepsake cards
- Aggregate reports and CSV export
- Free/pro session and attendee limits
- Cinematic marketing landing page
